# 残課題・対応状況

更新日: 2026-10-19

## 環境が必要な未完了項目

1. ブラウザで実際の3D描画、なでる、おもちゃ、ごはん、視点操作、モデル保存を確認する。
   - ブラウザ接続の一覧が空。Windows操作ヘルパーはnative pipe unavailableで、再試行・セッション初期化後も復旧しない。
   - HTTP 200、GLBの構造・必須ノード、障害物回避・給餌位置到着の検査は合格。視覚的・操作上の成功を代替するものではない。
2. 実マイクで録音・認識・読み上げを確認する。
   - 操作用接続とマイク権限が必要。録音の順序・末尾flush・空録音の自動テストは合格。
   - 鳴き声や合成音声が実際に聞こえるかは未確認。
3. OpenRouter・TTSQuestへ実接続して会話成功・音声再生を確認する。
   - ローカルの.dev.varsにOPENROUTER_API_KEYが未設定。キーはチャットへ貼らず、ローカルで設定する。
   - 実サーバーのキー未設定503/no-store、および模擬通信によるAPI成功・入力上限・再試行・上流失敗は確認済み。

## 対応済み

- Python 3.12.10・pre-commit 4.7.0・Gitleaks 8.24.2をGit除外済みwork/へ準備。Gitフックを有効化。
- 追跡済み＋未追跡（Git除外を除く）の全ファイル検査を実装。Gitleaks・秘密ファイル混入・個人メール・ローカルユーザーパス・独自語を検査。合成キー遮断と検知値の非表示もテスト済み。
- 独自語は00.secret/security-keywords.jsonから読む方式へ変更。サンプルと手順を01.docへ用意。実際の個人名・会社名の指定がないため配列は空。サブモジュールの変更・追跡解除は不要。
- Node.js 22.23.3をプロジェクト指定し、本番ビルド成功。システムNodeは変更していない。WindowsのNode.js 24.11.1で0xC0000409を再現するため、本プロジェクトでは検証済み22系を使う。依存ライブラリ単位の根本原因は未特定（運用上は22系で回避）。
- Lint指摘に対応。npm run lint成功。非推奨録音APIをAudioWorkletへ移行。
- 本番起動時にメイン画面・レビューが500となる問題を、3Dモジュールのクライアント側遅延読み込みで解消。本番5経路すべてHTTP 200。

検証方法・結果は01.doc/検証結果.md、検査環境の手順は01.doc/security-checks.mdを参照。
コミット・pushは今回実施していない。
