## 対応済み

- メイン画面のデバッグ用ボタン・モデルレビュー/比較/声の試聴リンク・モデル保存を通常非表示へ変更。/?debug=1で再表示可能。待機中の音声準備表示も非表示にし、処理中・エラー時は表示する。
- F2の標準調整値を利用者指定の0.92倍・+3.0半音・0.06秒で確定し、コードへ保存。個別保存がない場合に適用。「アプリの標準」で復元可能。
- 利用者の好みに合わせF2を初期値とし、速さ・高さ・文の間隔の調整、調整例3種、元のF2との比較試聴、保存と会話への適用を追加。好みの調整値と聴感は利用者による確認待ち。モデルの軽量化は未実施。
- 公式プリセットF1〜F5・M1〜M5の試聴・会話への適用・ブラウザへの保存を実装。声IDごとに特徴データを取得し、共通モデルを再利用。PCMキャッシュも声ごとに分離。利用者による好みの声の選択・聴感確認は引き続き残件。
- 試聴・保存・会話での声の指定を含む自動テスト計15件、Lint、本番ビルド、HTTP検査に合格。試聴画面と部屋の往復を通常のページ遷移に変更し、既存vinextのクライアント遷移エラーを回避。
- 外部TTSQuestの待ち時間を減らすため、ブラウザ内Supertonic 3 / WASM / Workerへ移行。「声を準備・試聴」、モデルキャッシュ、文単位再生、直近8文の音声再利用、失敗表示と再試行を追加。外部音声合成APIへの文章送信を削除。
- 会話APIに128トークン上限・低遅延プロバイダー優先・所要時間ログを追加。音声合成ライブラリの分割・再生順・解放・異常後の再試行テスト4件合格。詳細は01.doc/ブラウザ音声合成.md。
- 利用者による実操作で、画面表示・猫の歩行・鳴き声・なでる・おもちゃ・ごはんを確認。
- マイク不要の「こんにちは」送信ボタンを追加。OpenRouterへの実接続で日本語の返答を確認し、利用者からも会話成功の報告あり。
- APIキーを00.secret/.dev.varsに配置し、npm run startから明示的に読み込む方式へ変更。キーの値は記録しない。
- 認証エラー解消後、旧モデル指定の404を確認。会話用のgoogle/gemma-4-26b-a4b-it:freeへ変更。429利用制限・401認証失敗を画面で区別する処理を追加。
- Node.js 22.23.3とnpmをworkへ準備。依存ロックの不足を修復。Lint・ビルド・APIテスト5件に合格し、再起動後の画面・素材・入力検証も確認。
- 現在の確認用URLはhttp://127.0.0.1:3010/。起動手順はnpm run start -- --ip 127.0.0.1 --port 3010。
- Python 3.12.10・pre-commit 4.7.0・Gitleaks 8.24.2をGit除外済みwork/へ準備。Gitフックを有効化。
- 追跡済み＋未追跡（Git除外を除く）の全ファイル検査を実装。Gitleaks・秘密ファイル混入・個人メール・ローカルユーザーパス・独自語を検査。合成キー遮断と検知値の非表示もテスト済み。
- 独自語は00.secret/security-keywords.jsonから読む方式へ変更。サンプルと手順を01.docへ用意。実際の個人名・会社名の指定がないため配列は空。サブモジュールの変更・追跡解除は不要。
- Node.js 22.23.3をプロジェクト指定し、本番ビルド成功。システムNodeは変更していない。WindowsのNode.js 24.11.1で0xC0000409を再現するため、本プロジェクトでは検証済み22系を使う。依存ライブラリ単位の根本原因は未特定（運用上は22系で回避）。
- Lint指摘に対応。npm run lint成功。非推奨録音APIをAudioWorkletへ移行。
- 本番起動時にメイン画面・レビューが500となる問題を、3Dモジュールのクライアント側遅延読み込みで解消。本番5経路すべてHTTP 200。
