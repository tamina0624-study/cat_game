# ブラウザ内の日本語音声合成

更新日: 2026-10-19

## 利用手順

1. ローカルサーバー起動後、http://127.0.0.1:3010/ を再読み込みする。
2. 「声を準備・試聴」を押す。初回に約400MBを取得し、画面に進捗を表示する。
3. 試聴が終わったら「こんにちはを送る（マイク不要）」またはマイクで会話する。

音声はSupertonic 3の公式プリセットF1〜F5・M1〜M5を日本語で使う。初期値は利用者が選んだF2（保存済みの別の声は維持）。「声を試聴」画面で同じ文章を聞き比べ、「この声を使う」を押すと次の会話から適用する。選択はlocalStorageに保存し、再読み込み後も保持する。試聴だけでは会話の声を変更しない。旧VOICEVOXの春日部つむぎとは別の声。通常の会話文・履歴はOpenRouterへ送信するが、音声合成のための文章送信は行わない。

## F2のカスタマイズ

アプリ標準のF2は、利用者が選んだ速さ0.92倍・高さ+3.0半音・文の間隔0.06秒。コードのF2_DEFAULT_TUNINGに保持し、個別保存がないブラウザではこの設定を使う。「アプリの標準」でこの値に戻せる。保存済みの個別設定と「元のF2と比較」の調整前音声は維持する。

「声を試聴」画面上部で話す速さ（0.85〜1.20倍）、高さ（-2〜+3半音）、各合成文の間隔（0〜0.5秒）を調整できる。「そのまま」「ふんわり」「明るめ」の調整例と、元のF2との比較試聴を用意。

「このF2設定を会話に使う」を押した時だけ、F2の選択と調整値を保存する。試聴中の未保存値は会話へ反映しない。他の声の調整値には影響しない。

モデルの再学習や声の特徴データの書き換えはしない。話す速さは合成のspeed引数、高さはWeb AudioのplaybackRateで調整する。高さによる再生速度の変化を合成速度で補正するが、声の質感は変化する。合成速度もキャッシュのキーに含める。実際の間隔は合成自体の無音区間や次の文の準備時間により長くなる場合がある。

## 実装

- `02.src/lib/browser-tts.ts`: 再利用できるブラウザ用API。`unlock`、`prepare`、`speak`、`stop`、`dispose`を提供。PCMをWeb Audioで順次再生する。
- `02.src/lib/browser-tts.worker.ts`: 単一Workerで初期化・合成を直列化。ONNX Runtime Web / WASMを使用し、モデルのセッションを保持する。クロスオリジン分離やWebGPUは不要。
- 100文字以内の文単位で合成し、最初の文から再生する。声IDと文章をキーとして直近8件のPCMをメモリに保存し、同じ声・同じ文章の再合成を省く。違う声の音声は混在させない。
- 各声の特徴データは約0.29MBで、選んだ声だけ遅延取得・キャッシュする。声を切り替えても共通モデルのセッションは再初期化しない。モデルサイズの量子化・軽量化は未実施。
- 固定リビジョンのモデルをHugging Faceから取得。Cache Storageに保存して再読み込み後も再利用する。容量不足時はメモリだけで動作する。初回は約398MBと音声スタイル・設定・WASMランタイムを取得する。
- 会話APIの出力上限は128トークン。OpenRouterへ低遅延のプロバイダーを優先する指定を送信する。無料モデルを継続使用し、有料モデルへは切り替えない。
- コンソールに会話API時間と最初の音声までの時間を記録する。サーバーのOpenRouter応答概要にもelapsedMsを記録する。APIキーは記録しない。

## 検証

検証用Chrome、WASM単一スレッド、同一端末での短い日本語による実測。ネットワーク混雑や端末性能で結果は変わる。

| 条件 | 結果 |
| --- | --- |
| 初回取得・キャッシュ・日本語音声生成 | 成功 |
| 保存済みモデルから新Workerを準備 | 約659ms |
| 準備済みWorkerで未合成の短文2件 | 最初のPCMまで約1,472ms / 1,099ms |
| 同じ短文の音声再利用 | 最初のPCMまで約19ms |
| 音声データ | 44,100Hz、有限値・空でない波形・非ゼロ振幅を確認 |

上記は会話生成時間と実際に音が聞こえるまでの機器遅延を含まない。旧TTSQuestとの同条件比較は未実施。利用者による新しい声の聴感確認・実マイクからの一連の確認は残件。

分割・連続再生・終了時解放・Worker異常後の再試行を自動テストする。

```powershell
node --test 02.src/lib/browser-tts.test.mjs
```
